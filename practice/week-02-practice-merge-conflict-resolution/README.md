# Practice Merge Conflict Resolution

## Task Brief
Simulate and resolve a merge conflict between two feature branches to build conflict-handling confidence.

## Scenario
Two features modify the same file. Resolve the conflict, test the merge, and document the resolution.

## Deliverables
- Resolved merge conflict in portfolio repo
- Conflict resolution documentation

## Success Criteria
- Conflict markers removed and code is valid
- Merged branch contains both feature changes
