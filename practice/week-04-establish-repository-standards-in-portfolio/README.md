# Establish Repository Standards in Portfolio

## Task Brief
Apply .gitignore, README documentation, and branch protection rules to your existing portfolio repository.

## Scenario
Your team requires consistent repo standards. Configure your portfolio repo with proper setup practices.

## Deliverables
- Updated README with setup instructions
- Configured .gitignore file

## Success Criteria
- README documents project purpose and setup steps
- Sensitive files excluded via .gitignore
