# Create Concurrent Feature Branches and Resolve Merge Conflict

## Task Brief
Create two feature branches, make conflicting changes, and resolve the merge conflict in your portfolio repository.

## Scenario
Your team is working on parallel features. Create two branches with conflicting edits and practice resolving the conflict safely.

## Deliverables
- Two feature branches with conflicting changes
- Resolved merge conflict with clear commit message
- Updated main branch with merged feature

## Success Criteria
- Conflict markers identified and resolved correctly
- Merge commit documents resolution approach
- Repository history shows clean merge
