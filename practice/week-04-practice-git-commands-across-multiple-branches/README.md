# Practice Git Commands Across Multiple Branches

## Task Brief
Execute core Git commands: create branches, stage changes, commit with messages, and push across multiple feature branches.

## Scenario
Your team needs to verify command proficiency. Create and manage multiple feature branches with clean commit history.

## Deliverables
- Three feature branches with distinct commits
- Clean commit messages following conventions

## Success Criteria
- Each branch contains at least one meaningful commit
- Commit messages follow conventional format
